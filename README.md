# Ai-mizu PWA starter

透析患者さん向けの水分管理PWAの試作版です。

## 入っている機能
- 「今日あと飲める目安」を最優先表示
- 1日の水分目安（初期値800mL）
- DW表示・設定
- 服薬の水60mL / コップの水200mL / お茶200mL / コーヒー150mL / 牛乳200mL / ペットボトル500mL / 汁物150mL / その他
- 外出中タグ
- 今日の記録一覧
- 削除＋元に戻す
- 過去7日間グラフ
- ブラウザ内保存（localStorage）
- PWA / オフライン対応

## GitHub Pages
1. このフォルダ内のファイルをGitHubリポジトリのルートにアップロード
2. Settings → Pages
3. Deploy from a branch → main / root を選択
4. 公開URLをSafariで開く
5. 共有 → ホーム画面に追加

※ 現段階では患者個人の端末内だけにデータ保存する試作です。サーバーには送信しません。
